5. 선택한 후보로 메시 OBJ 내보내기

현재는 점 데이터만 준비되어 있습니다. 검증되지 않은 인덱스로 OBJ를 내보내지 않도록 미리보기에서 면 연결 상태를 확인하세요.

분석 로그가 여기에 표시됩니다.

사용 순서와 한계

  1. EBO를 선택하고 정점 오프셋 / 개수를 확인한 뒤 정점을 추출합니다.
  2. 3D 창에서 점들이 얼굴 형태로 배열되는지 확인합니다.
  3. 인덱스 후보 검색을 실행하고 후보를 선택합니다.
  4. 메시 미리보기에서 면이 얼굴 표면을 자연스럽게 덮는지 확인합니다.
  5. 정상적인 연결임을 확인한 뒤 메시 OBJ를 저장합니다.

이 도구는 파일을 서버로 전송하지 않습니다. 브라우저 메모리 안에서 처리합니다. 현재 EBO 포맷의 전체 명세가 알려져 있지 않으므로, 헤더·정점 추출·인덱스 후보 탐색을 지원하지만 모든 EBO에서 삼각형을 자동 복원한다고 보장하지 않습니다. UV / 노멀 / 본 / 모프 데이터는 아직 OBJ로 변환하지 않습니다.
